## 6. 알려진 약점 (신뢰도가 낮은 부분 — 우선 의심할 것)
1. 규정 값이 **2차 출처**(기사·블로그·검색 요약) 기반이다. 특히 LTV 적용 대상, 대출 상한 시행 세부, 취득세 구간, 전세 낀 매수 특례.
2. **남양주 다산동**은 "지정 목록에 없음"으로 비규제·비토허제를 *가정*했다.
3. 엔진 선택이 **같은 기간 데이터로 이뤄졌고**, 검증 기준이 같은 원천 데이터의 독립 *지수*일 뿐 정답이 아니다. 완만한 구간(2024~2026) 하락 재현은 20~38%로 낮다.
4. 새 엔진의 범위는 두 모델 중 넓은 쪽(보수적)으로 정했지만 **커버리지는 검증하지 않았다**.
5. 하락기 방어력은 분기 거래가 충분한 735개 단지에만 있고, 고점·저점이 잡음에 끌릴 수 있다.
6. 스트레스 금리 3.0%p는 **2026-12-31까지**라는 기사 한 건에 의존한다.
7. 금리 4.0%·만기 30년·전세가율 60%는 근거 없는 가정값이다.
8. 테스트의 Python 독립 구현은 같은 사람이 작성했고, 취득세·중개보수 공식은 구현과 같은 해석을 공유한다.
9. 헤드리스 Chrome 하니스(iframe 조작)는 실제 터치·접근성을 검증하지 못한다.
