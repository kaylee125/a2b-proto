# UI/UX 개선 기록 (3회 루프)

원칙: 계산·데이터·핵심 기능은 건드리지 않고 **표시, 흐름, 문구, 접근성**만 바꾼다. 매 루프마다 화면을 캡처해서 보고(480~520px, 360px, 다크), 문제를 찾아 고치고, 테스트로 고정한다. 기준 여정은 "내 집 고르기 → 후보 찾기·비교 → 필요한 돈 확인"이다.

## 시작 전 진단 (UX 리뷰)
홈에서 "필요한 돈"이 맨 아래에 있고, 자금 계획은 입력 9개 아래에 결과가 있으며, 10년 차트가 끊긴 선으로 보였다. 색 의미가 겹치고(빨강 = 상승·부족·토허제), 전문 용어가 많았고, 키보드 포커스가 없었다.

## 루프 1 — 여정의 핵심(필요한 돈을 바로 보이게)
| 찾은 문제 | 바꾼 것 |
|---|---|
| 홈에 갈아타기 결과가 없다 | 홈 맨 위에 **"A → B 갈아타기 한눈에"** 카드(부족/남는 돈, B에 필요한 돈, 현금 입력 전 표시). 기존 하단 CTA는 이 카드로 통합 |
| 자금 계획에서 입력 중 결과가 안 보인다 | **결과 요약을 화면 위에 고정**(입력 때마다 갱신). 현금을 아직 안 넣었으면 "보유 현금 입력 전(0원 기준)" 표시 |
| 입력이 한 덩어리, 만원 단위를 읽기 어렵다 | A를 팔 때 / B를 살 때 / 내 자금으로 묶고, 입력칸 아래에 **"10억 5,000만"** 처럼 한글 금액을 실시간 표시(0은 숨김) |
| 10년 차트가 끊긴 조각으로 보인다 | 거래가 모자란 구간을 **점선으로 이어** 보여주고 설명 문구 추가 |
| 후보 찾기 입력 요약이 없다 | 접힌 "내 자금"에 연소득·현금 요약 |
| (직접 수정) 값이 0인 칸마다 "0만"이 반복 | 0이면 한글 금액을 숨김 |

## 루프 2 — 이해도와 의사결정
| 찾은 문제 | 바꾼 것 |
|---|---|
| 전문 용어("임계", "주변 대비 -5.7%p", "중위") | "±3% 기준", "중간값보다 5.7%p 낮아요", "최근 6개월" 등 쉬운 말로 |
| 빨강이 상승·부족·토허제에 모두 쓰임, 토허제 칩이 카드마다 반복 | 토허제는 **앰버**로, 전부 토허제인 입지는 안내를 **한 번만** |
| 필터 칩 3줄 + 정렬 칩 5개 | 라벨(내 평형과 비슷한 범위 / 보여줄 결과)을 붙이고 **정렬은 선택 상자**로 |
| 단지 상세에서 다음 행동이 안 보인다 | 상단에 **다음 행동 버튼**(후보면 "자금 계획", "A와 비교" / 내 집이면 "후보 찾기" / 아니면 "후보에 추가") |
| 첫 실행 안내가 가치를 전달 못한다 | "1 내 집 고르기 · 2 후보 비교 · 3 필요한 돈 확인" 3단계 |
| 탭에 후보 찾기가 없다 | 하단 탭 5개(홈·후보 찾기·입지·자금 계획·설정) |
| 시나리오 표기가 어렵다 | "A 비싸게 팔고 B 싸게 사면" 등 |

## 루프 3 — 접근성과 마무리
| 찾은 문제 | 바꾼 것 |
|---|---|
| 키보드 포커스 표시가 없고 카드는 키보드로 닿지 않는다 | `:focus-visible` 윤곽, 카드·줄 전체를 누르는 요소에 `role="button"`·`tabindex`와 Enter/Space 동작 |
| 차트에 대체 설명이 없다 | 모든 차트·미니 그래프에 `role="img"` + 설명 |
| 작은 글씨(11px)와 작은 터치 영역 | 칩·힌트 12px, 칩·필터 버튼 최소 높이 34px |
| 360px에서 "2018 / 년"이 줄바꿈된다 | 연식 묶음 줄바꿈 방지 |
| 오래 걸리는 화면에 반응이 없다 | 350ms 넘으면 "불러오는 중…" 표시 |
| 용어가 어렵다 | 설정에 **용어 설명**(추세·확실·참고용·가능/빠듯/불가·환금성 등), 홈에서 링크 |
| 후보 찾기에서 긴 규칙 안내가 화면을 덮는다 | 규칙 카드를 **접어 두고** 기준일 경고만 항상 표시 |
| 입력이 많다(후보 찾기) | 핵심(보유 현금·연소득)만 먼저, 나머지는 "더 정확하게 계산하려면" 안으로 |
| 관심 입지 비교가 어렵다 | 2곳 이상이면 **"한눈에 비교" 표**, 순위에 "상위 N%" |
| "최고 대비 +0.0%" 같은 어색한 표시 | "10년 중 최고"로 |

## 추가 — 온보딩 가이드 (2026-10-14)
사용자 여정(서비스 이해 → 내 집·후보 → 숫자 읽기 → 후보·입지 → 필요한 돈)을 5단계 시트로 안내한다.

| 단계 | 내용 |
|---|---|
| 1 | 서비스가 하는 일 3가지, "추정이고 투자 권유가 아님·기기에만 저장" |
| 2 | 내 집(A)과 후보(B) 정하기 — "내 집 고르기" 버튼으로 바로 시작 |
| 3 | 숫자 읽는 법 — 실제 배지(상승·확실, 주춤·추정, 참고용)로 설명 |
| 4 | 조건으로 후보 찾기·관심 입지·A와 B 비교 — 줄을 누르면 해당 화면으로 이동 |
| 5 | 필요한 돈 — 입력하면 정확해지는 항목, ㎡/평 버튼, 용어 설명 위치 |

- **자동 시작은 한 번만**: 처음 방문 때 열리고 곧바로 저장돼 다시 방문하면 뜨지 않는다. `nosplash`(테스트)나 `sheet=` 주소에서는 자동으로 열지 않는다.
- **다시 보기**: 설정의 "사용 가이드 다시 보기", 홈 아래쪽 "사용 가이드". `?tour=1`로 강제 열기.
- **조작**: 건너뛰기, 이전/다음, 바깥 눌러 닫기, Esc, 대화 상자 역할·포커스(`role="dialog"`, `aria-modal`).
- **다듬은 것**: 처음에는 "다음" 버튼에 포커스 링이 보여 거슬려 대화 상자 자체로 포커스를 옮겼고, 4단계의 같은 모양 버튼 3개를 줄 전체를 누르는 목록으로 바꿨다.

## 검증
- `pytest` 101개 통과(데이터 12 + 화면 82 + `verify/` 7). 온보딩 테스트: 주소로 열기, 5단계 제목과 버튼, 시작하기·다시 보기·Esc·링크 이동, 첫 방문 자동 시작과 재방문 시 미표시, 진입점(홈·설정).
- (UX 루프 기준 97개였고 온보딩 테스트 4개를 더했다.) 새 UX 테스트: 자금 계획 고정 요약·한글 금액·현금 입력 전 표시, 홈 요약과 자금 계획 금액 일치, 상세 다음 행동, 후보 찾기 필터·토허제 안내·규칙 접힘, 키보드·차트 접근성, 관심 입지 비교 표, 설정 순서.
- 캡처로 확인: 520px, 360px(홈·자금 계획·후보 찾기), 다크 모드(홈).

## 자체 정정
리뷰에서 "후보 찾기의 핵심 입력이 접혀 있다"고 한 것은 일부 틀렸다. 연소득을 넣기 전에는 이미 펼쳐져 있었다(접힌 것은 연소득이 주소로 들어온 캡처였다). 그래서 루프 1에서는 접힌 상태의 입력 요약만 더했고, 루프 3에서 핵심 입력 2개를 먼저 보이게 했다.

## 남은 과제 (하지 않은 것)
- **후보 카드 압축**: 후보 찾기 카드가 여전히 크다(표·컴팩트 보기, 보조 버튼 아이콘화 미적용).
- **차트 터치 툴팁**: 24개월 차트 외에는 값을 눌러 보는 기능이 없다.
- **실기기·보조기기 검증**: 실제 폰 터치, 스크린리더(VoiceOver)로는 확인하지 못했다. 키보드 포커스와 역할 속성은 코드와 테스트로만 확인했다.
- **로딩 화면**: "불러오는 중…"은 코드로 넣었지만 실제로 보이게 느린 환경에서 확인하지 못했다.
- **컬러 대비 정량 측정**: 회색 보조 글씨의 대비비를 측정하지 않았다.
- 입력 흐름을 단계형(위저드)으로 바꾸는 큰 변경은 하지 않았다.
