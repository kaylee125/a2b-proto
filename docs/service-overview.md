## 2. 기능 목록 (무엇을 하고, 어떻게 계산하나)

### A. 단지 상세 화면
- **시세 범위**: 단지·평형·층(저/중/고)을 고르면 추정 시세 중간값과 90% 범위. 같은 단지의 최근 24개월 거래를 층·평형 차이를 보정한 회귀로 계산한다.
- **6개월 추세 (상승/주춤/하락)**: 최근 6개월 가격 변화율 추정치. ±3% 안이면 "주춤". 범위 전체가 ±3%를 넘으면 "확실", 아니면 "추정".
  - 계산: (24개월 창의 '최근 6개월 속도' 모델 + 12개월 선형 모델)의 평균. 범위는 두 모델 중 넓은 쪽.
- **참고용 / 표본 부족**: 최근 12개월 거래 12건 미만이거나 최근 3개월 거래 2건 미만이면 상승·하락 라벨을 붙이지 않고 평균만 보여준다("참고용"). 그것도 어려우면 "표본 부족".
- **주변 대비**: 같은 동(없으면 같은 구)에서 추세를 낸 단지가 6개 이상일 때 "중위 대비 몇 %p, 몇 개 중 몇 위".
- **10년 흐름**: 2016년부터 분기별 가격 지수.
- **하락기 방어력**: 2020Q4~2022Q4 고점에서 2024Q2 저점까지의 낙폭과 고점 회복에 걸린 분기 수. 같은 구 단지 중위 낙폭과 비교.
- **환금성**: 최근 12개월 신고 거래 수, 마지막 거래 후 경과일, 추세 계산에 쓰인 표본 수. (**거래 건수만 본다** — 팔 때 가격이 얼마나 밀리는지는 반영하지 않는다.)
- **최근 거래 목록**, 24개월 차트(점을 누르면 거래·추세 확인).

### B. A↔B 비교
표(시세·추세·주변 대비·환금성 등)와 "10년 상대 흐름" 그래프(같은 시점을 100으로 맞춰 비교), 하락기 낙폭·고점 회복.

### C. 자금 계획
- **필요 자금** = B 매수가 + 취득세 + B 중개보수 + 법무·등기(0.3%) + 이사비(기본 300만원) − B 대출 − (갭이면 전세 승계) + (거주 보증금)
- **A 매도 후 손에 쥐는 돈** = A 매도가 − A 대출 잔액 − A 중개보수 − 양도세(입력값)
- **부족/여유** = 필요 자금 − A 매도 후 돈 − 보유 현금
- 취득세는 1주택·일시적 2주택 가정(6억 이하 1%, 6~9억 구간식, 9억 초과 3%, 지방교육세, 85㎡ 초과 농특세 0.2%), 중개보수는 서울·경기 조례 요율표+한도액. 모두 **추정**.
- 대출은 연소득을 넣으면 LTV·수도권 상한(6/4/2억)·DSR(스트레스 금리 3.0%p 하한)로 계산. 금리 4.0%·만기 30년은 **가정값**.
- 시나리오·민감도, 토허제 안내, 일시적 2주택 처분기한 안내.

### D. 조건으로 후보 찾기
입지(구·동) → 살 방법(주담대/갭) → 가구 연소득·보유 현금 → 단지 목록을 **가능 / 빠듯 / 불가**로 분류.
- **가능** = 추정 시세 범위의 **높은 쪽(90% 상단)까지** 내 자금으로 감당
- **빠듯** = 중간값까지만 감당
- **불가** = 중간값도 못 감당
- 갭 모드에서 토지거래허가구역 단지는 "갭 불가"로 빼고, 토허제 단지를 켜서 보면 "갭 불가"로 표시.
- 구별 **최대 매수 가능가**(이진 탐색)를 상단에 표시.

### F. 관심 입지 (동·구 단위 가격 추이와 환금성)
- **고르기**: 동 또는 구·시를 최대 5곳. 선택 시트에서 이름으로 검색할 수 있다(공백 무시, 여러 단어는 모두 포함, 구·시를 동보다 먼저 40개까지, 선택한 입지는 ✕ 칩으로 위에 표시). 처음에는 내 집(A)이 있는 동이 자동으로 선택된다. 단지 상세의 "이 동의 가격 추이·환금성 보기"로도 들어온다.
- **가격 추이**: 입지 안 단지들의 분기 가격에서 단지별 가격 수준 차이를 빼고 합친 지수(첫 유효 분기 = 100). 분기마다 단지 5개 이상 있을 때만 만든다. 6개월·12개월 변화, 최고 분기 대비, 2022~23 하락기 낙폭과 회복, 같은 층위 안 순위, 84㎡ 환산 시세(최근 12개월 거래 ㎡당 중위가, 참고).
- **환금성(거래 활발도)**: 최근 12개월 거래 수와 전년 대비, 10년 평균 대비, 단지당 거래(순위), 거래가 있던 단지 비율, 최근 3개월 거래, 하락기 거래량 변화, 4분기 합 거래량 추이(10년 평균 = 100).
- **그룹핑**: 동이 얇으면 가격 추이는 생략하고 환금성만 보여준 뒤 구·시로 올려 보도록 안내한다. 입지 카드에서 "이 입지에서 살 수 있는 단지 찾기"로 후보 찾기로 이어진다.
- 한계: 세대수를 몰라 '단지당 거래'는 큰 단지가 많은 곳에서 높게 나온다. 거래량은 거래 12건 이상 단지만 센다. 최근 분기는 신고 지연으로 거래량에서 뺀다.

### E. 기타
**온보딩**: 처음 방문 때 5단계 사용 가이드(서비스 소개 → 내 집·후보 정하기 → 숫자 읽는 법 → 후보·입지 둘러보기 → 필요한 돈)가 한 번만 자동으로 열린다. 설정·홈에서 다시 열 수 있다.
내 집(A)·후보(B) 편집(⋮ 메뉴), 첫 실행 예시(관악구 벽산블루밍·노원구 한진한화그랑빌), 설정(면적 단위·테마·데이터 기준·내 정보 초기화). **면적 단위**: 상단 바의 `㎡ | 평` 버튼으로 모든 화면의 전용면적을 ㎡ 또는 평(전용 환산)으로 표시한다. 공급면적 기준 평형(34평형 등)과 다르다는 점을 설정 화면에 안내한다. 입력값은 브라우저에만 저장.

### 수록 데이터
국토부 실거래 2016-10~2026-09, **6,251개 단지**(10년간 거래 12건 이상). 서울 25구, 구리, 하남, 남양주 다산동, 수원 4구, 성남 분당, 안양 동안, 의왕, 화성 동탄구. 추세 라벨이 붙는 단지는 2,141개.

## 4. 이상한 점 — 내가 판단해서 고칠 것

### 4-1. 추세 표시가 과장되는 경우 (엔진)
- 발견: 최근 거래가 없는 단지에서 실제 약 -2~-4%인데 **-54%, "확실 하락 -16.8%"**가 표시됨. 원인은 최근 거래가 적을 때 '최근 속도' 모델이 마지막 거래 이후를 외삽해 극단값을 내는 것.
- 조치: 최근 3개월 거래 2건 미만이면 "참고용"으로 돌림. 대부분 해결.
- **남은 문제**: 마포래미안푸르지오3단지처럼 최근 3개월에 거래가 2건 이상(다른 평형)이라 가드를 통과하는데도 "확실 하락 -16.8%"(실제 약 -2%)가 남아 있음.
- **내 결정 필요**: 두 모델(최근 속도 vs 12개월 선형)의 값 차이가 크면 "확실"을 달지 않을까? (기본 제안: 예)

### 4-2. "가능/빠듯/불가" 기준
- "가능"은 시세 범위 **상단까지** 감당해야 하므로 꽤 보수적이다. 예산이 빠듯한 사람에게 "가능" 단지가 적게 보일 수 있다.
- **내 결정 필요**: 이 기준이 내 감각과 맞는가? (대안: 중간값 기준 "가능", 상단 기준 "여유")

### 4-3. 환금성의 정의
- 단지 상세는 여전히 "최근 12개월 신고 거래 수 + 마지막 거래 후 경과일"뿐이다. 입지 화면(2026-10-14 추가)은 거래 수의 전년·10년 평균 대비, 단지당 거래, 하락기 거래량 변화까지 본다.
- 둘 다 가격이 얼마나 밀렸는지, 세대수 대비 회전율은 보지 못한다(세대수 데이터가 없다).
- **내 결정 필요**: 단지 상세에도 입지 화면 수준의 환금성(추이·순위)을 넣을지, 세대수를 외부에서 가져와 회전율로 바꿀지.

### 4-4. 가정값과 가정 지역
- 금리 4.0%, 만기 30년, 전세가율 60%는 **근거 없는 가정**(화면에 표시됨, 직접 변경 가능).
- 남양주 다산동·수원 권선구는 "지정 목록에 없음 → 비규제·비토허제" **가정**. 동탄구는 규제·토허제로 계산하지만 지정 경계는 공식 고시와 대조하지 못함.
- **내 결정 필요**: 이 가정들이 맞는지 직접 확인(구청·국토부 고시)하거나, 불확실하면 보수적(규제 쪽)으로 둘지.

### 4-5. 데이터 자체의 한계
- 2020-02·2021-11 이전 취소·직거래가 섞여 초기 ㎡당가가 낮게 나올 수 있음 → 10년 지수·방어력에 영향.
- 최근 1~2개월은 신고 지연으로 건수가 적다.
- 방어력은 거래 활발한 단지에 치우친다.

### 4-6. 기획상 비어 있는 것
- 비교와 자금 계획이 한 화면이 아니다(§1-3).
- **입지 단위 추이·환금성이 없다(§1-4, 5).**
- 계정·기기 간 동기화 없음, 데이터 갱신은 수동, 배포 안 됨.

## 5. 직접 확인해 볼 체크리스트 (앱을 열어 눈으로)

1. 홈 → 내 집 A 카드: 예시 A 단지(98㎡ 9층)의 추정 시세와 6개월 추세가 데이터 값과 같은가. 주변 대비 순위가 보이는가.
2. 단지 상세 → 차트의 점을 눌러 **실제 거래가 맞는지**(날짜·금액·층)를 국토부 실거래 사이트와 한두 건 대조.
3. 거래가 적은 단지를 열었을 때 "참고용"으로 뜨고 라벨이 없는가.
4. A↔B 비교 → 10년 상대 흐름에서 2022~23년에 누가 더 빠졌는지가 내 기억과 맞는가.
5. 조건으로 후보 찾기 → 노원구를 고르고 가구 연소득·보유 현금을 넣으면 구별 최대 매수가가 나오는가(대출 상한이 바뀌는 15억 구간이 기준).
6. 같은 화면에서 갭 모드로 바꿔 서울 지역이 "갭 불가"로 빠지는가. 다산동은 갭 계산이 나오는가.
7. 자금 계획 → 숫자를 손으로 한 번 계산해 앱 결과와 맞는지(§2-C의 식).
8. 폰 브라우저로 열어 글자가 잘리지 않는지, 다크 모드가 읽히는지(**아직 아무도 확인하지 않은 부분**).
9. 평소 잘 아는 단지 2~3개를 골라 추세 라벨이 체감과 맞는지.

이 중 어긋나는 것이 있으면 어느 화면의 어느 숫자인지 알려주면 원인을 추적한다.
